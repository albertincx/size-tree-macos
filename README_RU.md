# FolderViewer для macOS

Нативное, легковесное и быстрое приложение на **SwiftUI** для просмотра дерева папок и файлов с мгновенным кэшированием размеров и пересчетом по требованию.

---

## ✨ Возможности

- 🌳 **Иерархическое дерево файлов и папок**:
  - Мгновенное раскрытие и сворачивание вложенных подпапок.
  - Нативные системные иконки macOS (`NSWorkspace`).
  - Отображение размера файлов и общего размера папок.
  - Подсчет количества вложенных объектов.
  - **Чекбокс «Показывать файлы»**: возможность скрыть обычные файлы и оставить только дерево директорий.
  - Сортировка: по размеру (по убыванию/возрастанию), по имени, по дате изменения.
  - Мгновенный поиск и фильтрация в реальном времени.

- ⚡ **Умное кэширование размеров**:
  - Размеры папок кэшируются на диске (`~/Library/Application Support/FolderViewer/folder_size_cache.json`).
  - Повторное открытие папок происходит **мгновенно** без повторного сканирования диска.
  - Закешированные папки отмечаются бейджем **⚡ Кэш** с относительным временем последнего подсчета.
  - Фоновый асинхронный подсчет для папок, которых ещё нет в кэше.

- 🔄 **Пересчет размеров для закешированных элементов**:
  - **Главная кнопка в тулбаре «Пересчитать размер»**:
    - Пересчет всех видимых папок в текущем виде.
    - Выпадающее меню: *«Пересчитать выбранную папку»*, *«Пересчитать все видимые папки»*, *«Пересчитать весь сохранённый кэш»*.
  - **Индивидуальная кнопка пересчета** (🔄) прямо на строке каждой папки.
  - **Контекстное меню** (правый клик по папке) со пунктом *«Пересчитать размер»*.
  - **Окно управления кэшем** (кнопка в правом нижнем углу): просмотр размера файла кэша на диске, полный пересчет или очистка.

- 🧭 **История путей и навигация**:
  - Кнопки **Назад (⌘[)** и **Вперёд (⌘])**.
  - Меню недавних папок (`clock.arrow.circlepath`) в заголовке и тулбаре.
  - Список недавних папок на стартовом экране.
  - Постоянное сохранение истории (`UserDefaults`).

- 🌐 **Двуязычность (Русский / English)**:
  - Автоматическое определение языка системы (`Locale.preferredLanguages`).
  - Быстрое переключение через переключатель **RU / EN** в строке состояния.

- 🍎 **Интеграция с macOS**:
  - Поддержка **Drag & Drop** (перетащите любую папку из Finder прямо в окно).
  - «Показать в Finder», «Открыть в Терминале», «Скопировать путь» по правому клику.
  - Чистый нативный интерфейс SwiftUI под macOS 14+ Sonoma / Sequoia.

## 🚀 Быстрый запуск

Запустить собранное приложение:
```bash
./run.sh
```
или открыть бандл напрямую:
```bash
open FolderViewer.app
```

---

## 🛠 Сборка из исходников

### Требования:
- macOS 14.0 или новее
- Xcode Command Line Tools (`swift --version` >= 6.0)

Собрать релизный бандл `.app`:
```bash
./build_app.sh
```

Или запуск в режиме разработки через Swift Package Manager:
```bash
swift run
```
